game.js 
const engine = Lument;
engine.init({ width: 800, height: 600, title: 'My Game' });
engine.run(() => {
    engine.clear({ r: 30, g: 30, b: 40, a: 255 });
    engine.drawCircle(400, 300, 50, { r: 100, g: 200, b: 255, a: 255 }, true);
});
// 在 800×600 画布上每帧清屏并绘制一个青色圆
版本历史

持续 演进

从 v1.2.0 的全栈能力铺陈，到 v1.3.0 的易用性与性能深耕，Lument 稳步向前。

v1.2.0上一稳定版

全栈能力成型：物理 / 音频 / 网络 / AI / ECS 齐备

  • 2D 物理模拟：刚体动力学、自定义阻尼、重力、碰撞检测与响应
  • 3D 空间音频：MP3/WAV/OGG、空间定位、音量与音调控制
  • 网络模块：HTTP/HTTPS 请求、WebSocket 长连接、数据同步
  • AI 模块：行为树、有限状态机、A* 寻路、黑板系统
  • 图形渲染增强：后处理、粒子系统、精灵动画、纹理图集
  • ECS 系统：稀疏集合 O(1) 查找
v1.3.0最新版本

易用性与性能深耕：UI 自动化 · 渲染批处理 · 物理空间分区 · 工程化

  • UI 系统自动化：9 类新控件、主题系统、auto-sizing、声明式 JSON 构建、FLOW 布局
  • 基础渲染图元：circle / line / triangle / polygon / ellipse / point
  • 手动批处理 API：beginBatch / batchQuad / endBatch，单次 drawCall
  • 物理空间分区：Uniform Grid 与 Quadtree 宽相位、调试渲染、碰撞对计数
  • 工程化：npm 包、TypeScript 类型定义、示例、62 项测试套件
