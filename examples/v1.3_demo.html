UI Automation

Theme system, new v1.3 controls (dropdown, toggle, slider, checkbox, spinner, divider, tooltip), declarative JSON UI and auto-size. Every box on the canvas is a real Lument widget created with the v1.3 uiCreate* API and drawn by uiRender(). Click the checkbox / drag the slider on the canvas.
—

Rendering Primitives

drawCircle, drawLine, drawTriangle, drawPolygon, drawEllipse, drawPoint and the manual batch API beginBatch / batchQuad / batchTriangle / endBatch. Toggle layers and watch them animate in the main loop.
Batch mode renders many quads + a triangle inside a single beginBatch() … endBatch() pass.

Physics Spatial Partitioning & Debug

physicsSetBroadphase (grid / quadtree / brute), physicsSetGridCellSize, physicsDebugDraw and physicsGetPairCount. Bodies collide and bounce; the broadphase grid is drawn by physicsDebugDraw.
