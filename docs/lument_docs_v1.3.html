Lument Engine
v1.3.0

Lument Engine 文档

轻量级 2D 游戏引擎 · 渲染 / 物理 / UI / AI / 网络 / ECS 全栈支持。

1. 快速开始

Lument Engine 通过单一全局对象 Lument 暴露全部能力。在页面中引入引擎脚本后即可初始化一个画布并启动主循环。

最小示例

// 1. 初始化引擎，挂载到 #game 画布
Lument.init({
  canvas: '#game',
  width:  960,
  height: 540,
  renderer: Lument.RENDERER.WEBGL
});

// 2. 注册每帧更新逻辑
Lument.run(function() {
  Lument.beginFrame();
  Lument.clear(0x16213e);

  Lument.drawRect(100, 100, 64, 64, 0xe94560);

  Lument.endFrame();
});

// 3. 关闭引擎
// Lument.shutdown();
引擎默认使用 WebGL 渲染器，在不支持 WebGL 的环境会自动降级到 Canvas2D。

2. 核心 API

核心 API 负责引擎生命周期与主循环调度。

Lument.initinit(options: InitOptions): void

初始化引擎，绑定画布并配置全局参数。必须在调用任何渲染 API 之前执行。

参数类型说明
options.canvasstring | HTMLCanvasElement画布选择器或元素，必填
options.widthnumber逻辑宽度（像素），默认 800
options.heightnumber逻辑高度（像素），默认 600
options.rendererRENDERER渲染器类型，默认 WEBGL
options.dprboolean是否启用设备像素比，默认 true
options.vsyncboolean是否启用垂直同步，默认 true

返回值：void

Lument.init({
  canvas: '#game',
  width:  1280,
  height: 720,
  renderer: Lument.RENDERER.WEBGL
});
Lument.shutdownshutdown(): void

停止主循环、释放 GPU 资源并销毁上下文。调用后引擎进入未初始化状态。

返回值：void

Lument.shutdown();
Lument.isRunningisRunning(): boolean

返回主循环是否正在运行。

返回值：boolean — 是否正在运行

if (Lument.isRunning()) {
  console.log('引擎运行中');
}
Lument.beginFramebeginFrame(): void

标记一帧渲染开始，重置内部统计并准备绘制上下文。必须在每帧绘制前调用。

返回值：void

Lument.beginFrame();
Lument.endFrameendFrame(): void

提交当前帧绘制命令并执行缓冲区交换。与 beginFrame 成对出现。

返回值：void

Lument.endFrame();
Lument.getDeltaTimegetDeltaTime(): number

返回上一帧到当前帧的时间间隔（秒，浮点）。用于实现帧率无关的运动。

返回值：number — 秒

const dt = Lument.getDeltaTime();
x += speed * dt;
Lument.getStatsgetStats(): FrameStats

返回当前帧的性能统计信息。

返回值：{ fps:number, drawCalls:number, vertices:number, frameTime:number }

const s = Lument.getStats();
console.log(`FPS=${s.fps} draws=${s.drawCalls}`);
Lument.getPlatformgetPlatform(): string

返回当前运行平台标识（与 Lument.PLATFORM 常量匹配）。

返回值：string — WEB / MOBILE / DESKTOP 之一

if (Lument.getPlatform() === Lument.PLATFORM.MOBILE) {
  // 启用触控 UI
}
Lument.getRendererTypegetRendererType(): string

返回当前激活的渲染器类型。

返回值：string — WEBGL / CANVAS2D / WEBGPU 之一

console.log(Lument.getRendererType()); // "WEBGL"
Lument.runrun(callback: (dt:number)=>void): void

启动主循环并以指定回调作为每帧入口。回调参数 dt 为帧时间（秒）。

参数类型说明
callback(dt:number)=>void每帧调用，dt 为帧间隔（秒）

返回值：void

Lument.run((dt) => {
  Lument.beginFrame();
  // ... 渲染逻辑
  Lument.endFrame();
});

5. 手动批处理 v1.3 新增

当需要精确控制绘制顺序与状态切换时，可使用手动批处理通道，将多个图元合并为一次绘制调用。

Lument.beginBatchbeginBatch(maxVerts=4096): void

开启一个批处理上下文，maxVerts 为顶点缓冲上限。

返回值：void

Lument.batchQuadbatchQuad(x,y,w,h,color): void

向当前批次追加一个四边形。

返回值：void

Lument.batchTrianglebatchTriangle(x1,y1,x2,y2,x3,y3,color): void

向当前批次追加一个三角形。

返回值：void

Lument.endBatchendBatch(): void

提交并清空当前批次。一次绘制调用渲染所有累积的图元。

返回值：void

使用示例

Lument.beginBatch(8192);
for (let i = 0; i < 500; i++) {
  Lument.batchQuad(i*2, 100, 2, 20, 0xe94560);
}
Lument.endBatch(); // 1 次 drawCall 渲染 500 个矩形
批处理必须在 beginFrame/endFrame 之间调用；同一批次内图元共享渲染状态，切换纹理会强制提交。
