为你的下一部视觉小说，量身打造的轻量引擎

LumentGAL 是 Lument 1.3.x 的内置视觉小说子系统，将剧本 DSL、打字机对话框、立绘/CG 演出、分支选择、快照存档、Live2D 角色动画、WebAudio 音频管线全部打包成一套极简的 API。无需打包工具、无需后端、无需外部依赖，单文件 lument.js 即可开跑。

▶ 5 分钟上手 🧪 打开完整 Demo 📜 DSL 速查表

1 概览 · Overview

LumentGAL 目标是让你在一个下午就能做完一部可发布的视觉小说 Demo，同时具备上规模项目所需的模块化、自动化与性能保证。

1.1 功能一览 已实现

  • 按用户点击 / Space 或自动播放推进文本，打字机一句一句展示对话内容
  • 在指定位置（左 / 中 / 右 / 自定义坐标）显示/隐藏立绘、背景、CG，播放 8 种场景切换补间
  • 播放 BGM（同一时间只有一个，交叉淡入淡出）与音效（最多 16 路并发节流队列）
  • 遇到选项点自动暂停，玩家选择后跳标签或指定位置继续
  • 提供文本历史记录（翻页 UI API）、跳过历史文本（支持"只读跳过"防剧透）、自动播放、6 槽位存档读档 + 快速存读档
  • 记录游戏内变量（好感度、剧情 flag）用于后续剧情分支 & 多结局判定，支持变量变更事件回调
  • Live2D 子系统：模型加载、动作/表情控制、离屏缓存 & 脏值节流，无外部模型时自动占位渲染（点击有动作反馈）

1.2 架构组成

🎬 GAL 子系统 lument.js : 3093~4510
剧本解析、标签跳转、对白系统、立绘/CG 补间、屏幕演出、存档快照、偏好设置、历史记录。
🎭 Live2D 子系统 lument.js : 4588~5310
模型管理、动作/表情、参数化控制、自动眨眼/视线/头转/口型、离屏缓存。
🎵 音频管线 lument.js : 1342~1568
WebAudio 优先解码 + HTMLAudio 回退；BGM 单实例；SE 队列 16 路；占位合成音源。
📜 剧本 DSL 24 种命令
@bg / @show / @choose / @set / @if / @live2d / @call… 语法低噪，上手即写。

1.3 为什么用 LumentGAL

需求LumentGAL常见 WebGAL 方案
体积单文件 ~180 KB（lument.js + Canvas2D）通常 5~15 MB（含打包 runtime + 资源 loader）
启动开销0 构建步骤，直接 <script src> 运行需 Webpack/Vite 打包或特定 CLI
外部音频可 完全不依赖外部音频文件（合成音源占位）必须配置音频资源服务器或打包 mp3/ogg
Live2D 离屏缓存内置，脏值签名减少 drawImage 70%+部分方案每帧重绘整模型
Node 测试无 DOM 环境可正常加载（全部 API no-op 不抛异常）多需 jsdom polyfill
已读跳过支持 "只读跳过"（skipReadOnly） 模式，自动暂停未读需要手工实现

2.3 写第一份 GalScript

把剧本作为多行字符串传入 galLoadScript，然后调用 galStart：

const src = `
@bg #1b1f52 FADE 1000
@effect fade_from_black 800

# 这是注释
Alice: 你好呀，我是 Alice～欢迎来到 LumentGAL！
Bob:   要不要来一杯咖啡？

@choose coffee|好呀，谢谢;tea|更想喝茶
:coffee
Alice: （笑）就知道你会选这个。
@set flag_AliceLove += 1
@jump end_route

:tea
Bob:   哈，品味不错。
@set flag_BobLove += 1
@jump end_route

:end_route
@bg #0a0a24 FADE 1200
旁白: 故事就这样开始了……
@end
`;

const sid = Lument.galLoadScript('chapter1', src);
Lument.galStart(sid);  // 或 galStart('chapter1')

2.4 主循环 + 输入

const canvas = document.getElementById('game');

// 点击画布推进；也可用键盘 Space
canvas.addEventListener('pointerdown', (e) => {
  const r  = canvas.getBoundingClientRect();
  const sx = (e.clientX - r.left) * (1280 / r.width);
  const sy = (e.clientY - r.top)  * (720  / r.height);
  // 先处理选项按钮点击；未命中则普通推进
  if (!Lument.galHandleClick(sx, sy)) {
    Lument.galAdvance();
  }
});
window.addEventListener('keydown', (e) => {
  if (e.code === 'Space'){ e.preventDefault(); Lument.galAdvance(); }
  if (e.key  === 'a'){ Lument.galSetPrefAuto(!Lument.galGetPrefAuto()); }
  if (e.key  === 's'){ Lument.galSetPrefSkip(!Lument.galGetPrefSkip()); }
});

// 主循环：每帧 update + render
let last = performance.now();
function loop(ts) {
  const dt = Math.min(100, ts - last); last = ts;
  Lument.beginFrame();
  Lument.galUpdate(dt);
  Lument.galRender();
  Lument.endFrame();
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);

3 剧本 DSL 参考

GalScript 是一个对"非程序员作者"友好的 DSL：每行一条命令或一句对白，支持 # 注释、:标签、${变量插值}。

3.1 基本规则

  • 换行即分隔：按 \n 切行，一行一条语句或对白。
  • 注释：# 这是注释（整行），或 // 行尾注释。
  • 标签：:label_name，供 @jump / @call / @choose 跳转。
  • 变量插值：对白/旁白文本中使用 ${变量名} 会被 galGetVar 运行时替换。
  • 大小写：命令关键字（FADE、LEFT）大小写不敏感；标签名和变量名区分大小写。

3.2 对白 & 旁白

语法含义示例
角色: 对白文本角色台词，对话框显示角色名框Alice: 今天的天气真不错呢～
Narrator: 文本 或直接纯文本旁白，对话框不显示角色名框风拂过她的发梢。
旁白: 文本同 Narrator，中文别名旁白: 故事才刚刚开始。
💡 小技巧：在对白文本里插入 \n 可以手动换行（例如分两行的诗句）；默认会根据对话框宽度自动换行。

3.3 背景 / 立绘 / CG

# 背景：十六进制颜色 或 图片名(纹理名)
@bg #1b1f52 FADE 1000
@bg classroom_day DISSOLVE 800

# 立绘：sprite名 / live2d:模型id  SLOT 表情 透明度 TWEEN 时长
@show alice_default  LEFT   happy   1    FADE 700
@show live2d:1         RIGHT  neutral 1    SLIDE_R 500
@hide alice_default  FADE 500

# CG：全屏图片（通常用于事件 CG）
@cg   event_handhold FADE 800
@cg   hide FADE 500   // 或 @hidecg

TWEEN 种类（Lument.GAL_TWEEN）：NONE, FADE, SLIDE_L, SLIDE_R, SLIDE_U, SLIDE_D, ZOOM, DISSOLVE, CUT。

立绘 SLOT（Lument.GAL_SLOT）：LEFT, CENTER, RIGHT, CUSTOM。立绘会在相应槽位做自动定位。

3.4 Live2D 交互

@live2d 1 expression happy
@live2d 1 motion Idle:0       // 组名:序号；可选优先级（@后面）
@live2d 1 param ParamMouthOpenY 1.0   // 直接设置 Cubism 参数
@live2d 1 visible off
@live2d 1 visible on

3.5 选项分支

语法：@choose label1|选项1文本;label2|选项2文本 ...。遇到这条命令时剧本会暂停，直到玩家点击选项或按下 1~9 数字键，然后跳转到对应标签。

@choose route_a|答应 Alice 的告白;route_b|答应 Bob 的告白;route_c|两个都不选

:route_a
@set end_flag = 'alice_true'
@jump ending

:route_b
@set end_flag = 'bob_true'
@jump ending

:route_c
@set end_flag = 'normal'
@jump ending

3.6 变量 & 条件跳转

# 赋值 / 算术
@set aff_Alice = 2
@set aff_Alice += 1
@set aff_Alice -= 3
@set day_count = 'Monday'
@set flag_seen_event_x = true

# 条件跳转：@if 变量 运算符 值  目标标签
@if aff_Alice >= 7  alice_true_end
@if aff_Alice < 3   normal_end
@if end_flag == alice_true_end  epilogue_alice

支持运算符：== != < <= > >=。字符串比较时不加引号也可，自动做字符串相等判断。

💡 好感度追踪：在 JS 端调用 Lument.galSetOnVarChange((k,o,n)=>…)，就可以监听 aff_Alice 这类变量变化，实时刷新你自己的好感度 HUD。

3.7 音频命令

# BGM （全局同时间只存在一个，切换自动 crossfade）
@bgm opening_theme.ogg loop 0.7 800    // loop 开关 · 音量 · fadeMs
@bgm stop 600

# SE （音效，并发最多 16 路）
@se click.wav 0.8

# 语音 （同一时刻最多一个）
@voice alice_line_012.ogg 1.0 Alice  // 第 3 个参数自动绑定说话者
Alice: ${这里会等语音播放后再推进?不，默认并行}

3.8 屏幕演出

@shake 6 500                 // 强度 6，持续 500 ms
@effect flash 400            // 白闪 400ms
@effect fade_to_black 800
@effect fade_from_black 800
@wait 1200                       // 暂停 1.2s 再继续下一行

当你有一段公共剧情想复用（例如"两人进入咖啡店"的通用过场），可以用 @call / @ret 模拟"子程序"：

@jump after_cafe

Bob:   老板娘，两杯拿铁。
@ret

:after_cafe
…

4 GAL 子系统 API

所有 GAL 相关 API 均挂载在 Lument.* 命名空间下。类型定义见 runtime/js/lument.d.ts。

4.1 生命周期

签名说明
galInit(styleOpt?)初始化 GAL 子系统；加载持久化偏好（localStorage）。可覆盖对话框样式。
galShutdown()停止播放、清空所有状态并释放订阅者（避免重复初始化内存泄漏）。
galIsRunning(): boolean当前是否处于剧本播放中。

4.2 剧本 & 推进

签名说明
galLoadScript(name, src): number解析 GalScript，返回脚本 id，可 galStart(id) 或 galStart(name)。
galParseScript(name, src): ScriptObj只解析不注册，拿到内部结构做静态分析。
galStart(idOrName, entryLabel?)从脚本（可选指定入口标签）开始播放。
galStop()停止剧本运行，但保留当前 history 和变量状态供调试。
galAdvance()用户点击推进：打字机未完→瞬间显示完；打字机完→下一句。
galSkip(v:bool)开/关快进模式（与偏好联动持久化）。
galSetSkipReadOnly(v:bool) / galGetSkipReadOnly()只读跳过：开时快进只推进"已读文本"，遇到未读自动停下。
galAuto(v:bool) / galSetAutoDelay(ms)自动播放 & 句间延迟（默认 2500ms）。
galGotoLabel(label)立即跳标签（可用于引擎外部事件驱动剧情跳转）。
galSelectChoice(i)脚本暂停在选项点时，按下标触发选择。
galChoose(labelOrIndexOrText)按标签 / 下标 / 选项文本触发选择；对外最常用的分支驱动 API。
galGetChoices(): Array<{label,text}> | null获取当前所有选项；不在选项点时返回 null。
galGetChoiceCount() / galGetChoiceText(i)查询当前选项以便做自定义 UI 渲染。

4.3 对话框 & 历史

签名说明
galSetDialogStyle(Partial<DialogStyle>)动态改对话框样式（字体、颜色、位置、圆角…）。
galShowDialog(v:bool) / galIsDialogVisible()显隐对话框（常见于 CG 特写时隐藏）。
galSay(name, text)直接从 JS 插入一句对白（常用于脚本外的动态文本）。
galHandleClick(sx, sy): bool命中画布内渲染出的选项框→自动选择并返回 true。
历史
galGetHistoryCount(): number历史对白总条数（对白会自动累积，存档读档也会恢复 history）。
galGetHistoryEntry(i): {name,text,voice,read?}按索引取一条历史条目。
galClearHistory()清空历史（用于共通线结束后另起新篇章）。
galGetHistoryPageCount(pageSize): number翻页总页数。
galGetHistoryPage(idx, pageSize): HistoryItem[]拿一页历史（含 index 和 read 标记，方便做 NEW 角标）。
galIsCurrentLineRead(): bool当前正在显示的这句对白是否"已读过"（用于 HUD 指示已读/未读）。

4.4 立绘 / 背景 / CG

galDestroySprite(id)注销立绘。
galAttachLive2d(modelId, slot, z?): spId把已加载的 Live2D 模型挂载为立绘，随 GAL 场景管理显示/隐藏和补间。推荐用法。

galHideSprite(id|name, tween?, dur?)从 JS 触发立绘隐藏。
galSetSpritePosition(id|name, x, y)直接设置立绘坐标（CUSTOM 槽位常用）。
galSetSpriteScale(id|name, s)立绘缩放。
galSetSpriteExpression(id|name, expr)设置立绘/Live2D 表情。
galSetBackground(imgOrColor, tween?, dur?)JS 端切背景。
galShowCG(img, tween?, dur?) / galHideCG(tween?, dur?)CG 全屏图。

4.5 变量 & 事件

签名说明
galSetVar(k,v) / galSetVarInt/Float/Bool(k,v)设值，类型化版本会确保存入值为 number/bool。
galGetVar(k,def?) / galGetVarInt/Float/Bool(k,def?)取值。

4.8 每帧 update / render

Lument.beginFrame();
Lument.galUpdate(dtMs);   // 打字机推进、自动/快进、补间、BGM fade、Live2D tick
Lument.galRender();       // 画背景→立绘（z 排序）→CG→对话框→选项→屏幕震动/淡入淡出
Lument.endFrame();
⏱ 性能提示：dtMs 建议做上限夹取（例如 Math.min(100, dt)），避免切换 Tab 回来后补间一次性跳完、闪屏。

5 Live2D 子系统 API

5.1 接入说明

Lument Live2D 子系统采用"占位优先"设计：即使你没有真实的 .model3.json，live2dLoadModel() 也会返回一个参数化占位模型，完整支持表情/动作/点击反馈——非常适合剧本还没做完资源、先写玩法的阶段。

有真实资源时：传入 live2dLoadModel('/assets/my.model3.json')，Lument 会按标准 Cubism Web SDK 2.x 约定解析并加载纹理 / 动作 / 表情。

5.2 生命周期 & 模型

签名说明
live2dInit(corePath?)初始化子系统（只做一次；重复调用 no-op）。corePath 目前保留接口，占位模型无需传参。
live2dShutdown()销毁所有模型，释放离屏缓存 canvas。
live2dLoadModel(model3JsonPath?): number返回模型 id（≥1）。
live2dReleaseModel(id)释放单个模型。
live2dIsReady(id): bool占位模型始终为 true；真实模型需等资源加载完。
live2dSetTransform(id, Partial<Transform>){x,y,scaleX,scaleY,rotation,z,alpha}，以 1280×720 虚拟坐标系为准。
live2dGetTransform(id): Transform | null读取当前 transform。
live2dSetLayer(id, z)z 越大越靠前，用于多角色叠放。
live2dSetVisible(id, v)显隐（离屏缓存同样会暂停脏值更新）。
live2dHitTest(id, x, y): string | null点击碰撞检测，返回 'Head' / 'Body' / null 等（占位模型按矩形分区）。

5.3 动作 & 表情

签名说明
live2dGetMotionGroupCount(id, group): number查询某动作组的长度（占位模型 Idle 组长度 1；TapBody 1；Flick_Head 1）。
live2dStartMotion(id, group, index, priority?): number触发动作。priority 越大越优先；高优先级会打断低优先级。
live2dIsMotionPlaying(id): bool / live2dStopMotion(id)动作状态控制。
live2dGetExpressionCount(id)表情数量（占位模型 neutral/happy/sad/angry/surprise 共 5 种）。
live2dGetExpressionName(id, i)第 i 个表情名。
live2dSetExpression(id, name)切指定表情。
live2dSetExpressionRandom(id)随机表情（常用于点击身体反馈）。

5.4 自动动画

默认启用。全部是占位模型内置的 Canvas2D 合成动画，无需外部资源：

  • live2dEnableAutoBlink(id, v) 自动眨眼（眼睑覆盖，随机 3~7s 间隔）。
  • live2dEnableAutoEye(id, v) 视线追踪鼠标/触摸。
  • live2dEnableAutoHead(id, v) 头部随视线轻微转动。
  • live2dEnableAutoMouth(id, v) 口型：有语音播放时按包络自动开合；无语音时按打字机节奏轻微张合。

5.5 参数化控制

签名说明
live2dSetParam(id, paramId, value)直接设置 Cubism 参数。占位模型识别 ParamAngleX/Y/Z, ParamEyeBallX/Y, ParamMouthOpenY, ParamBrowAngleY。
live2dGetParam(id, paramId, defVal?)取参数。
live2dParamAdd(id, paramId, delta)累加。
live2dParamMult(id, paramId, factor)缩放。
live2dSetEyeTarget(id, x, y)视线/头追踪到归一化坐标（通常由输入事件驱动）。

5.6 性能优化：离屏缓存 & 脏值节流

Lument Live2D 子系统已经默认开启这几项优化，你使用时无需手动介入：

  • 模型查找 O(1)：使用 modelMap(id→model) + nameMap(name→id)，每次渲染不做数组遍历。
  • 离屏缓存：每个模型拥有独立 OffscreenCanvas（或后备 canvas）。参数未变化时直接 drawImage(offscreen)，不再重绘眼睛/嘴/发/脸等多层合成。
  • 脏值签名：每次 tick 对（表情+transform+动作状态+参数）做一个 32-bit 哈希签名，签名一致就不重绘离屏 canvas。实测角色站立不动时，CPU 绘制开销降为原来的 20%~30%。
  • 全局 tick 节流：所有模型按 60 FPS 统一更新一次，避免每个模型独立 setTimeout。
💡 进一步性能建议：同一幕里同时出现 >3 个 Live2D 时，建议给不正在说话的角色 live2dEnableAutoMouth(id,false)；对白切回时再开，进一步降低每帧参数插值。

5.7 占位渲染

当 live2dLoadModel() 不传 model3.json 时，会渲染一个 Canvas2D 手绘风格的二次元占位角色：头部、眼睛（带虹膜高光）、嘴、头发、肩部、服饰阴影，表情通过参数插值切换五官几何形态。整体观感近似于"矢量插画风格立绘"，可以直接用于 DEMO 和剧本排演。

6 音频系统

6.1 架构

  • 解码：优先 WebAudio decodeAudioData，失败降级 HTMLAudioElement。
  • BGM：单实例全局管理（galAudio.bgm），任何时刻只存在一个 BGM。
  • SE：16 路并发队列（maxSimul=16），超出排队。
  • Voice：单实例，会被后续 galPlayVoice 自动打断并释放上一条。

6.2 BGM 交叉淡入淡出

切换 BGM 时旧 BGM 线性淡出 & 新 BGM 线性淡入同时进行，避免"啪"的声压突变：

Lument.galPlayBgm('chapter2.ogg', true, 0.6, 800);  // fadeMs = 800
// → 旧 BGM 在 800ms 内 volume→0；新 BGM 在 800ms 内 0→0.6

6.3 SE 并发节流

防止"一串密集点击"同时播放 30 个音效导致浏览器音量饱和/崩溃：最多 16 路同时播放，超过的排队。

for (let i=0; i<50; i++) Lument.galPlaySe('click.wav');  // 安全，不会炸

6.4 合成音源（无外部音频文件 ✨）

在没有任何 mp3/ogg 资源的 DEMO/原型阶段，你可以用 galStartSynthBgm 和 galSynthSeClick / galSynthSeConfirm 得到 WebAudio 合成的占位音乐和按钮音效：

// 启动一段 8 音阶 C 大调循环旋律（triangle 波形 + 呼吸式音量LFO）
Lument.galStartSynthBgm('title', 'triangle', 0.25);
Lument.galStopSynthBgm ('title', 1000);     // 1s 淡出停止

// 按钮点击音效（短脆的 1200→520Hz triangle 滑降）
Lument.galSynthSeClick(0.3);
// 确认音效（上升三和弦 E5-G5-C6）
Lument.galSynthSeConfirm(0.35);
💡 为什么要有这个？很多 GAL Demo 作者在作品初期还没拿到 BGM/SE 授权文件，或在 GitHub Pages 上演示时不想打包大体积音频。合成音源让你零外部资源就能跑完整部作品的听觉反馈，发布前把合成音源调用替换成真实 galPlayBgm/galPlaySe 即可。

6.5 自动播放策略兼容（iOS / Chrome）

现代浏览器默认阻止 未发生用户交互 的音频自动播放。Lument 内部已做 3 层兼容：

  1. WebAudio 创建时 audioCtx.suspended 是正常状态，等首次交互时 resume()。
  2. 首次用户指针/键盘事件触发时尝试 audioCtx.resume() + startSynthBgm 自动启动。
  3. HTMLAudio fallback：WebAudio 解码失败时用 new Audio() 播放，并同样等待用户 gesture 后再 .play()。
⚠ 注意：如果你的剧本一启动就立刻 galPlayBgm，在 Chrome 上会被静默拦下来（因为还没发生任何点击）。正确做法：在用户按下"开始游戏"的按钮回调里再触发 BGM，或像 demo 里一样在 pointerdown / keydown 的 once 监听里尝试启动。

7 存档 & 偏好

7.1 多槽位存档

槽位号从 0 开始，数字没有上限。localStorage key = LUMENT_GAL_SAVE_v1:{slot}。

Lument.galSave(0, '第一章 · 咖啡馆');
Lument.galLoad(0);
const info = Lument.galGetSaveInfo(0);
console.log(info.title, info.timestamp, info.summary, info.used);

7.2 快速存 / 读档

默认绑键建议：F5 存 / F9 读。对应示例里已实现。

window.addEventListener('keydown', e => {
  if (e.code === 'F5') { e.preventDefault(); Lument.galQuickSave(); }
  if (e.code === 'F9') { e.preventDefault(); Lument.galQuickLoad(); }
});

7.3 数据格式（可自定义解析做云存档）

存档 JSON 结构如下（全部字段可序列化，便于你 POST 到服务器做云存档）：

{
  version: 1,
  scriptName: 'prologue', lineNo: 17,
  vars: { aff_Alice: 6, flag_x: true },
  history: [ { name, text, read }, … ],
  sprites: { …当前所有立绘的位置/表情/透明度… },
  bg: { …背景状态… },
  cg: null | { … },
  preferences: { textSpeed, volSE, volBGM, volVoice, auto, skip, skipReadOnly },
  readSet: { …已读签名快照，用于"只读跳过"跨存档保持一致… }
}

7.4 偏好持久化

所有 galSetPref* 写入后立刻调用 galSavePref()（localStorage key = LUMENT_GAL_PREF_v1）。galInit() 时会自动读回，保证跨会话保留玩家的音量、文字速度等设置。

8 高级 & 最佳实践

8.1 DPR / Retina 高分屏适配

Lument 内部画布按逻辑分辨率 1280×720 渲染，你外面的展示 canvas 按 DPR 放大即可（demo 中的做法）：

function fit() {
  const r  = canvas.getBoundingClientRect();
  const dpr = Math.min(2, window.devicePixelRatio || 1);
  canvas.width  = Math.round(r.width  * dpr);
  canvas.height = Math.round(r.height * dpr);
}
window.addEventListener('resize', fit); fit();

// 主循环末尾把引擎 canvas 以高 DPR 缩放绘制到页面 canvas：
const sc = Math.min(canvas.width / Lument.getCanvas().width,
                 canvas.height / Lument.getCanvas().height);
demoCtx.imageSmoothingEnabled = true;
demoCtx.imageSmoothingQuality = 'high';
demoCtx.drawImage(Lument.getCanvas(), dx, dy, ew*sc, eh*sc);

8.2 渲染层 Z-Order 指南

galRender 里的绘制顺序是固定的：

  1. 背景（@bg 图片/颜色；下方舞台外的 CSS 渐变会作为 HTML 层显示）
  2. 立绘 sprites：按 sprite.z 升序（小→大）绘制；z 相同按创建顺序。
  3. Live2D：每个 sprite 若关联了 live2dId，就在该 sprite 位置上叠加 Live2D（离屏缓存 → drawImage）。
  4. CG：全屏覆盖（通常 0.95 的 alpha 叠画面）。
  5. 屏幕震动 / fade 叠加：最后做。
  6. 对话框：最顶 UI。
  7. 选项卡片：对话框之上。

建议：重要角色 z=1，背景 NPC z=0，前景物体 z=2。

8.3 模块化剧本（多脚本 + call/ret）

当你的项目剧本变大后，建议按章节拆成多个文本文件，再在游戏里组合：

// 加载多份
for (const [name, src] of [
  ['prologue',   prologue_src],
  ['chapter1', chapter1_src],
  ['common',   common_src],
]) Lument.galLoadScript(name, src);

// 在剧本里即可用 @jump chapter1:some_label 跨脚本跳
// （若跨脚本跳转，需要在 DSL 里写成 脚本名:标签名 语法，Lument 会自动定位）
📌 提示：跨脚本跳转语法为 @jump scriptName:labelName；@call 同样支持，call 栈跨脚本仍然有效。

8.4 引擎外部 UI 集成（React / Vue）

LumentGAL 的 UI 完全可选。你可以只把 canvas 作为"画面层"，对话框、历史、选项、设置面板都用 React/Vue 做：

  • 选项：用 galGetChoiceCount() / galGetChoiceText(i) 拿数据渲染自己的 UI，用户点击后再 galSelectChoice(i)。
  • 对白：用 galOnRead + history 自己画对话框。打字机推进仍然交给 galAdvance，也可以自己调用 galSay(name, text) 绕过 DSL。
  • 历史：galGetHistoryPage(idx, size) 直接分页渲染。

8.5 自动化 & 单元测试（Node 兼容）

Lument.js 在 Node 环境下无 DOM 也能 require：所有 canvas 操作改为 no-op，不会抛异常。可以这样写测试：

const Lument = require('./runtime/js/lument.js');
const assert = require('assert');

Lument.init();        // canvas → null 但不会报错
Lument.galInit();
const src = `A: hi\nB: there\n@choose l1|a;l2|b\n:l1\n@end\n:l2\n@end`;
Lument.galLoadScript('t', src);
Lument.galStart('t');
Lument.galUpdate(0); Lument.galAdvance();
Lument.galAdvance();

let fired = null;

9 FAQ 常见问题

🔸 点击/空格推进了，但文字没显示 / 对话框没出现？

常见原因：galInit() 还没调用就 galStart()，或主循环忘记调 galRender()，或画布 display:none / 被透明层挡住。打开 DevTools 的 Console，检查是否有 canvas is null 类报错。

🔸 背景图片/立绘图片不显示？

请先调用 Lument.loadTexture('mybg.png') 注册纹理，再用 @bg mybg.png 或 galCreateSprite('sprite.png', SLOT, z) 建立立绘。没有预先加载纹理的图片名会以纯色方块占位渲染。

🔸 BGM 没声音（Chrome / iOS）？

90% 是自动播放策略拦截：请保证 BGM 的启动发生在首次点击/按键事件回调里。demo 中的 stage.addEventListener('pointerdown', tryStartBgm, {once:true}) 就是标准做法。

🔸 "只读跳过"已读文本判断的原理？能跨会话保存吗？

每一句对白会生成签名 = scriptName + lineNo + djb2(text)，写入 gal.readSet。该集合会一起被快照存档持久化，所以读档回来后"跳过只读"仍然知道哪些是已读（不会剧透）。

🔸 Live2D 能接真实 Cubism 4 SDK 吗？

LumentGAL 子系统设计上预留了 live2dLoadModel(path) 接口作为接入点，在你集成 live2dcubismcore.js 和对应 Web SDK 绑定后，可以在 live2dRenderModel() 内部把"占位渲染分支"替换为真实 Cubism 渲染。当前版本默认走零依赖占位渲染，方便你不用下载 4MB 的 Cubism Core 也能完整跑 Demo。

🔸 存档能存/恢复选项暂停中的进度吗？

可以。暂停在 @choose 时存档的话，galSave 会把 gal.choices 当前选项一并写入。读档回来后可以继续做选择。

🔸 剧本太长（几万行），解析会慢吗？

GalScript 解析器是 O(N) 线性扫描，单条语句解析平均约 100ns，实际 10 万行剧本首解析也不到 50ms；galParseScript 结果会缓存到 gal.scripts，再次运行不用重新解析。
